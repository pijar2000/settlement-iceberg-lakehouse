# Data Dictionary (raw layer, implemented)

Generated by `python -m src.cli generate` into `data/raw/batch-seed<SEED>/`.

## internal_transactions
`transaction_id`, `merchant_id`, `provider`, `reference_no`, `amount` (IDR int), `currency`, `status` (SUCCESS/FAILED/PENDING), `created_at`, `updated_at`, `expected_settlement_date` (D+1), `source_file`, `batch_id`.

## partner_settlements/<PROVIDER>
Schemas differ per provider and are defined in `config/providers.yaml`; each file also has `source_file`, `batch_id`.

| Provider | Delimiter | reference / amount / status / date columns | Notes |
|---|---|---|---|
| OVO | `,` | ovo_ref / amt / trx_status / settle_date | `%Y-%m-%d` |
| DANA | `\|` | merchant_trans_id / amount_idr / status / settlement_time | `dd/mm/yyyy`, FAIL, PROCESSING |
| GOPAY | `,` | order_id / gross_amount / transaction_status / settlement_ts | ISO datetime, settlement/deny/pending |
| LINKAJA | `,` | trxRef / nominal / state / settled_on | amount in cents (x100), S/F/P |
| FINNET | `;` | inv_no / total / result_code / settle_dt | codes 00/99/01 |

## cdc_events
`event_id`, `lsn`, `op` (I/U/D), `event_ts`, `transaction_id`, `merchant_id`, `provider`, `reference_no`, `amount`, `currency`, `status`, `source_file`, `batch_id`. DELETE events carry the key only.

Bronze/Silver/Gold tables: planned (Phase 3+).
